# Mathematics content rules

- Verify every calculation, answer, unit, and stated condition independently.
- Each MCQ must have exactly one correct answer. Check every choice, including edge cases.
- Distractors must be plausible and incorrect; never include two choices that are mathematically equivalent.
- Use a valid chapter ID and non-empty topic tags that accurately describe the question.
- For repeating decimals, use clear recurring notation (for example, \(0.\overline{3}\)) or state an explicit rounding precision; do not present an approximation as an exact value.
- Phrase questions clearly and concisely, with all necessary information and no ambiguous interpretation.
- Write formulas with explicit grouping, operators, units, and variable meanings wherever omission could change the result.
