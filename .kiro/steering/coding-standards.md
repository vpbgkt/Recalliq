# Coding standards

- Use strict TypeScript and preserve type safety; avoid unnecessary casts.
- Keep functions small and reusable; prefer pure functions for logic.
- Separate game logic from UI components.
- Reuse existing project types, services, and helpers.
- Keep dependencies minimal and follow the local-first architecture.
- Make logic deterministic and straightforward to test.
- Avoid unnecessary backend, network API, or external-service infrastructure.
